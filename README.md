# 리뷰 & 아카이빙 허브 (MVP 기획)

모바일 우선으로 **빠르고, 간편하고, 보기 좋은** 리뷰/기록 경험을 제공하는 개인 허브형 앱의 MVP 기획서입니다.

## 1) 제품 목표 (Why)
- 내가 읽은/본 콘텐츠를 **60초 내 기록**하고 **짧게 평가**할 수 있다.
- 월/분기/연도 단위로 **소비량과 만족도**를 확인한다.
- 모바일에서 **한 손 입력 + 빠른 탐색**이 가능하다.

## 2) 핵심 사용자 시나리오 (When)
1. 사용자는 책/영화/드라마를 선택하고, **짧은 코멘트 + 평점**을 남긴다.
2. 콘텐츠는 자동으로 **아카이빙**되고, 카테고리(책/영화/드라마)로 정리된다.
3. 사용자는 **월/분기/연도 통계**에서 완료 수, 평균 평점, 총 소비량을 확인한다.

## 3) MVP 범위 (What)
### 반드시 포함 (Must)
- 콘텐츠 유형: 책/영화/드라마 구분
- 빠른 기록 폼
  - 제목, 유형, 완료일, 평점(1~5), 한줄평
  - 입력 최소화(자동완성/최근 목록, 최근 사용한 유형 프리셋)
- 리스트/카드 뷰
  - 최근 기록, 유형별 필터, 그룹 칩, 검색
  - 카드에 제목/유형/평점/완료일 노출
- 책장(그룹)
  - 원하는 그룹으로 묶어 기록을 관리
- 통계
  - 월/분기/연도별 완료 수
  - 평균 평점
  - 총 소비량(예: 읽은 권수, 시청한 편수)
- 저장/동기화
  - 계정 로그인(이메일) + 클라우드 저장

### 반드시 제외 (Later)
- 외부 독서 앱/OTT 연동
- 추천 알고리즘(장르/평점 기반)
- 소셜 기능(팔로우/공유)

## 4) 정보 구조 (IA)
- 홈: 최근 기록 + 빠른 추가 CTA + 이번 달 요약
- 기록: 목록/필터/검색
- 통계: 월/분기/연도 탭
- 설정: 계정, 데이터 내보내기

## 5) 핵심 화면 정의 (MVP)
- 홈
  - 상단: 이번 달 완료 수/평균 평점
  - 하단: 최근 5개 기록 카드 + “빠른 추가” 버튼
- 기록
  - 상단: 타입 필터(책/영화/드라마) + 검색
  - 목록: 카드형(제목/평점/완료일)
- 기록 작성
  - 입력: 제목/유형/완료일/그룹(책장)/평점/한줄평
  - CTA: 저장
- 통계
  - 탭: 월/분기/연도
  - 지표: 완료 수, 평균 평점, 총 소비량

## 6) 핵심 데이터 모델 (초기)
- Entry
  - id
  - type: book | movie | drama
  - title
  - completedAt
  - rating (1~5)
  - review (short)
  - createdAt
  - updatedAt
- Stats
  - period: month | quarter | year
  - count
  - avgRating
  - totalConsumption

## 7) UX 원칙 (How)
- **1분 내 기록 완료**: 입력 필드 최소화, 자동완성, 최근 기록 재사용
- **모바일 최적화**: 엄지 영역 배치, 카드형 리스트
- **가독성 중심**: 타이포 우선, 여백 넉넉히
- **한 눈에 파악**: 홈/통계 요약은 숫자 2~3개로 제한

## 8) 제품 지표 (MVP 성공 기준)
- 기록 완료 시간 평균 **60초 이내**
- 7일 재방문율 **30% 이상**
- 월간 재방문율 **40% 이상**
- 평균 리뷰 길이 **30자 이상**

## 9) 향후 확장 아이디어
- 외부 연동: 독서 앱/OTT 시청 기록 가져오기
- 추천: 유사 장르/평점 기반 콘텐츠 추천
- 위젯: 최근 기록/이번 달 통계 표시
- 내보내기: CSV/Notion 연동

## 로컬 실행 방법
- 브라우저에서 `index.html`을 직접 열면 됩니다.
- 입력 데이터는 브라우저의 LocalStorage에 저장됩니다.
- 미리보기를 위해 상단의 “샘플 불러오기” 버튼으로 예시 데이터를 추가할 수 있습니다.
